Browser extension

Load the extension folder in Chrome or Edge (Developer mode, Load unpacked). The app listens on 127.0.0.1:24680. The toolbar icon and the right-click menu always work. These two settings only apply to downloads the browser starts by itself.

Send links from your phone

Turn this on, scan a code with your phone camera, and paste any link on your phone. It starts downloading here. YouTube and screener.in links go to their own downloaders. Windows may ask once to allow Mjolnir on private networks. Choose Allow.
Phone page
Pair once with the code below. After that the phone remembers this PC: open the address above on the phone, or bookmark it or add it to the home screen. If this PC's address changes (it shows here), pair again with a new code. Your router can keep the address fixed with a DHCP reservation.

Paired phones

Anyone on your Wi-Fi holding a paired phone's key can queue downloads here. Remove a phone to cut it off.
